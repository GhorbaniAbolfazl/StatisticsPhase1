# بررسی نهایی و تطبیق با فایل درس

تاریخ بازبینی: ۲۰۲۶-۱۱-۰۳. مرجع الزامات: [فایل درس](amarpr.pdf)، به‌ویژه صفحات ۵ تا ۸ و ۱۸ تا ۲۰. دامنهٔ فعلی پروژه فاز یک، مسیر ج NACC است؛ تحلیل‌های احتمال، استنباط و مدل‌سازی فازهای بعد در این تحویل اجرا نشده‌اند.

## اصلاحات این بازبینی

- عنوان علمی PDF از عنوان Markdown خوانده می‌شود؛ تگ جهت‌دهی HTML عنوان گزارش نیست. فهرست پیونددار، نشانک‌ها و پیوند منابع اضافه و جدول‌های متراکم تفکیک شده‌اند.
- سبک شکل‌ها مستقل از تم روشن/تیرهٔ نوت‌بوک است. چهار تصویر نوت‌بوک با PNGهای مستقل و PDF تطبیق داده می‌شوند؛ ناهماهنگی مانع ساخت گزارش/بسته است.
- بخش ادامهٔ تحلیل و پیوند داخلی آن، توزیع صریح رکوردهای فعلی هر فرد و قاعدهٔ یک رکورد برای هر شناسه تکمیل شده‌اند.
- فهرست فایل‌ها، پیوندها و عبارت‌های منسوخ مستندات اصلاح شده‌اند. فایل‌های تاریخی ناموجود به‌عنوان مدرک معرفی نمی‌شوند.
- آزمون‌های قواعد، اتصال، مخرج‌ها، آمار، نمودارها، PDF و بسته‌بندی اضافه شده‌اند. شناسهٔ نامعتبر مانع اتصال می‌شود؛ اطلاعات موقت غیراستاندارد IDE پیش از اجرای تازه حذف می‌شود؛ خروجی stderr مانع جایگزینی نوت‌بوک موفق جدید است.
- سه CSV خام طبق قاعدهٔ فایل درس در Git نادیده گرفته می‌شوند و داخل ZIP تحویل نیستند. کپی‌های موقتِ تأییدشده برای بازتولید بسته استفاده می‌شوند.

## نتیجهٔ کنترل‌های اجرایی

| کنترل انجام‌شده | نتیجه |
|---|---|
| اجرای نوت‌بوک از هستهٔ تازه | ۴۳ سلول کل، ۲۴ سلول محاسباتی؛ صفر خطا و صفر stderr |
| آزمون‌های مستقل | ۳۹ آزمون موفق در پروژه و کپی استخراج‌شدهٔ بسته |
| کنترل محاسبات | بازسازی جدول افراد از ورودی؛ تطبیق مستقل هر ۵۴ ردیف خلاصهٔ عددی با NumPy؛ حفظ مخرج‌ها و عضویت |
| کنترل مستندات داده | ترتیب و نام هر ۱۸۰ ستون UDS و ۱۲۶ ستون MRI و تعداد مقادیر متمایز UDS با ورودی مطابق است |
| یکسانی تصویر | هر چهار PNG داخل نوت‌بوک با فایل مستقل یکسان است؛ تم تیره خروجی تصویر را تغییر نمی‌دهد |
| کنترل PDF | ۱۸ صفحه به‌صورت تصویری بازبینی شد؛ متن بیرون صفحه صفر؛ ۱۸ نشانک به صفحات درست و ۱۷ پیوند فهرست به بخش‌های درست اشاره می‌کنند؛ دو پیوند منبع فعال است |
| کنترل فایل‌ها و پیوندها | ۶۰ فایل موجود در فهرست محلی؛ ۲۷۰ پیوند محلی معتبر و ۲۲ اثر انگشت وابستگی/خروجی سازگار |
| بستهٔ تحویل | ۵۷ فایل پروژه و یک شناسنامهٔ بسته؛ سه CSV خام داخل ZIP نیستند؛ CRC و اثر انگشت تمام فایل‌های داخل بسته کنترل می‌شود |
| بازتولید کپی جداگانه | اجرای کامل از بستهٔ استخراج‌شده، برابری خروجی‌های تحلیلی و PDF و موفقیت ۳۹ آزمون تأیید شد |
| حفظ فایل‌های اولیه | هر سه CSV اولیه و PDF درس با اثر انگشت پیش از بازبینی یکسان‌اند |
| حفظ نتایج عددی | جدول افراد و پنج CSV جریان/مخرج/خلاصه‌ها با نسخهٔ قبل از اصلاح از نظر بایت یکسان‌اند؛ سیاست تحلیل و نتیجهٔ عددی تغییر نکرده است |

برای تکرار کنترل‌ها:

```bash
python3 scripts/run_phase1_notebook.py
python3 -m unittest discover -s tests -v
python3 scripts/package_phase1.py --check-root .
python3 scripts/package_phase1.py --reproduce
```

خروجی محلی تحویل `dist/phase-1-nacc.zip` و اثر انگشت آن در فایل همراه `.zip.sha256` است. تاریخچهٔ کار، برچسب Git و ارسال بیرونی از این نتیجه استنباط نمی‌شوند.

تعریف MoCA و کد ویژهٔ آن، کدهای وضعیت شناختی و منطق GDS با [مرجع رسمی UDS](https://files.alz.washington.edu/documentation/uds3-rdd.pdf) و نام/واحد ضخامت انتورینال با [مرجع رسمی MRI](https://files.alz.washington.edu/documentation/SCAN-MRI-Imaging-RDD.pdf#page=15) مقابله شدند. این تطبیق، اصالت نمره‌ها یا نسخهٔ آماده‌سازی زیرمجموعه را اثبات نمی‌کند.
