# پروژهٔ آمار — فاز یک، مسیر ج NACC

**موضوع:** ارتباط میانگین ضخامت قشر انتورینال دو نیمکره با نمرهٔ MoCA در زیرمجموعهٔ تحویلی NACC، با در نظر گرفتن سن، جنس و سال‌های تحصیل.


## شروع بررسی

1. [نوت‌بوک فاز یک](notebooks/phase1.ipynb) را برای متن، کد، جدول‌ها و چهار تصویر باز کنید؛ برای دیدن خروجی موجود اجرای دوباره لازم نیست.
2. [کارت پروژه](PROJECT_CARD.md) سؤال، متغیرها، جمعیت و طرح ادامه را مشخص می‌کند.
3. [گزارش فارسی](reports/phase1.pdf) را برای نسخهٔ مناسب مطالعه و چاپ باز کنید.
4. [راهنمای بررسی و پوشش الزامات](docs/PHASE1_DELIVERY.md) مسیر خواندن، نقش فایل‌ها و وضعیت تحویل را توضیح می‌دهد.

این پروژه فعلاً توصیفی است. اختلاف‌های گروهی، جهت یا اندازهٔ ارتباط فردی/تعدیل‌شده را برآورد نمی‌کنند؛ آزمون، ضریب همبستگی، مدل، فاصلهٔ اطمینان یا تحلیل حساسیت اثر اجرا نشده است. دامنهٔ ادعا در [جمع‌بندی](reports/phase1/conclusion.md) صریح است.

## داده و تصمیم‌های ثابت

سه فایل دیتا: [UDS](data/udslong_imputed.csv)، [MRI](data/mriscanclean.csv) و [ماتریس نواحی](data/combined_adjacency_matrix.csv). تاریخ دریافت ۱۰ اکتبر است؛ تعریف و منبع همهٔ فایل‌ها در [راهنمای داده](data/README.md) آمده است.

سه CSV اولیه محلی‌اند و طبق صفحات ۱۸ و ۱۹ فایل درس، به‌صورت پیش‌فرض داخل ZIP تحویل یا Git قرار نمی‌گیرند. برای بازتولید در رایانهٔ دیگر، همان فایل‌های تحویلی TA باید در پوشهٔ data قرار گیرند؛ نسخهٔ عمومی دیگری جایگزین آن‌ها نمی‌شود. [گزارش تطبیق نهایی](docs/PHASE1_FINAL_CHECK.md) نتیجهٔ کنترل‌ها و محدودیت‌های پوشش الزامات را ثبت می‌کند.

اصل CSVها و PDF درس بازنویسی نمی‌شوند. جدول مرجع با اتصال یک‌به‌یک NACCID، تمام **۱۲۳۷ فرد** را نگه می‌دارد و نمونهٔ هر خروجی با پرچم آن انتخاب می‌شود:

| مجموعه | تعداد |
|---|---:|
| زوج اصلی MoCA و میانگین ضخامت | ۱۲۲۸ |
| اصلی با سن، جنس و تحصیلات قابل استفاده | ۱۲۲۶ |
| زوج حساسیت فقط MoCA صحیح‌مقدار | ۹۸۴ |
| مشترک حساسیت با هر سه متغیر همراه | ۹۸۲ |

مجموعه‌ها هم‌پوشان‌اند و جمع نمی‌شوند. ۲۴۴ نمرهٔ اعشاری درون دامنه اصلی با پرچم حفظ‌اند؛ صحیح‌بودن هم اصالت را ثابت نمی‌کند. چهار MoCA=88 و پنج نمرهٔ دیگر خارج از دامنه و دو EDUC=99 در متغیر کاری مربوط غیرقابل استفاده‌اند؛ خام و علت حفظ‌اند. گردکردن، برش نمره، جایگذاری دوباره یا حذف خودکار بر اساس IQR انجام نمی‌شود. نبود یک متغیر فرد را از تمام توصیف‌ها حذف نمی‌کند.

## بازتولید کامل

برای اجرای تمام نوت‌بوک، **Python 3.11 یا جدیدتر** با وابستگی‌های [requirements.txt](requirements.txt) لازم است. در محیط Python مورد استفاده، از ریشهٔ همین پروژه:

```bash
python3 -m pip install -r requirements.txt
python3 scripts/run_phase1_notebook.py
```

فرمان دوم از همان Python یک هستهٔ تازه می‌سازد، همهٔ سلول‌ها را به ترتیب اجرا و پس از موفقیت نوت‌بوک را همراه خروجی ذخیره و سپس PDF فارسی و شناسنامهٔ آن را بازتولید می‌کند. نصب هستهٔ عمومی یا اجرای سرور Jupyter لازم نیست. مشاهده/اجرای تعاملی در محیط سازگار با ipykernel، مانند IDE یا Jupyter ازپیش‌موجود، هم ممکن است؛ برنامهٔ رابط Jupyter در requirements اجباری نشده است. نصب اولیهٔ بسته‌ها ممکن است اینترنت بخواهد؛ محاسبات و تولید شکل‌ها از فایل‌های محلی انجام می‌شوند.

اجرای کامل، گزارش‌های ممیزی، جدول مرجع و شناسنامه، جریان و مخرج‌ها، جدول‌های توصیفی، PNG/SVGها و PDF گزارش را بازتولید می‌کند. نتیجهٔ اجرای موفق در `notebooks/phase1.ipynb` می‌ماند. متن‌های تحلیلی و جمع‌بندی نوشته‌شده نیز همراه نوت‌بوک هستند؛ اگر ورودی یا سیاست آماری تغییر کند، متن‌ها باید با نتایج تازه بازبینی شوند.

آزمون‌های قواعد و محاسبات:

```bash
python3 -m unittest discover -s tests -v
```

اگر یکی از دستورهای مرحله‌ای زیر گزارش تغییر منبع/کد/قواعد یا خروجی ناسازگار داد، ابتدا اجرای کامل نوت‌بوک یا زنجیرهٔ مراحل را از ابتدا انجام دهید.

## اجرای مرحله‌ای

از ریشهٔ پروژه و به ترتیب وابستگی‌ها:

```bash
python3 src/phase1_quality.py --write-reports
python3 -m src.phase1_dataset
python3 -m src.phase1_descriptive
python3 -m src.phase1_figures
python3 scripts/build_phase1_pdf.py
```

| دستور/بخش | خروجی |
|---|---|
| ممیزی | متن و JSON ممیزی و ردگیری سلولی در reports/phase1 |
| اتصال و نمونه | جدول مرجع و شناسنامه در data/processed، جریان و مخرج‌ها در reports/phase1 |
| آمار توصیفی | سه CSV تجمیعی، JSON روش/نتایج و متن توصیفی |
| رسم | چهار PNG با وضوح ۳۰۰ dpi، چهار SVG، گزارش و متادیتای رسم |
| PDF | گزارش فارسی reports/phase1.pdf با فهرست پیونددار و نشانک بخش‌ها |

دستورهای مرحله‌ای خروجی داخل نوت‌بوک را تازه نمی‌کنند؛ برای آن از فرمان اجرای کامل استفاده کنید. اجرای ممیزی بدون نوشتن گزارش با `python3 src/phase1_quality.py` ممکن است. ممیزی/اتصال/جدول‌های عددی فقط کتابخانهٔ استاندارد Python 3.10 یا جدیدتر می‌خواهند؛ الزام Python 3.11 اجرای کامل از نسخهٔ NumPy ثبت‌شده می‌آید.

## ساخت و بررسی بستهٔ تحویل

پس از اجرای کامل و موفق آزمون‌ها:

```bash
python3 scripts/package_phase1.py --check-root .
python3 scripts/package_phase1.py --reproduce
```

ZIP و اثر انگشت آن در dist ساخته می‌شوند. دستور دوم اجرای نوت‌بوک و آزمون‌ها را در کپی موقت بسته تکرار می‌کند؛ سه ورودی خام از نسخهٔ محلی تأییدشده خوانده و فقط در کپی موقت قرار داده می‌شوند. نسخهٔ تحویل شامل PDF، کدها، نوت‌بوک، شکل‌ها، راهنماها، دادهٔ منتخب مشتق و آزمون‌هاست. جزئیات در [راهنمای تحویل](docs/PHASE1_DELIVERY.md) آمده است. ثبت موضوع، تاریخچهٔ Git و برچسب phase-1، انتشار GitHub و بارگذاری CW با دانشجوست؛ ساخت ZIP رسید ارسال نیست.
